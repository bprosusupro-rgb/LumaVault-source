Use LumaVault with EDS

LumaVault is the picture browser. EDS Lite remains the part that unlocks your VeraCrypt container.

  1. Prepare exFAT. If the container uses exFAT, install EDS Lite’s additional exFAT module first.
  2. Unlock the container. Open it in EDS Lite and keep it open while browsing.
  3. Scan the vault folder. Tap Choose a folder. In Android's picker, select the opened container by its own name (it may not be labelled “EDS Lite”), or choose the picture folder inside it. LumaVault scans nested folders for pictures.
  4. If the EDS location is not listed. Use EDS Lite's Share or Open with action on pictures and choose LumaVault. If EDS Lite offers multi-select sharing, send several pictures together.
  5. Browse. Use the folder list, search, sorting, and any picture to open the full-screen viewer.
  6. Finish safely. Close LumaVault, then close or unmount the container in EDS Lite.

No root is required. EDS Lite must stay unlocked while LumaVault reads the selected folder. The Android picker grants access only to the folder you choose; unmount the volume in EDS Lite when finished.
